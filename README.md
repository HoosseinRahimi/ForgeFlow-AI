# ForgeFlow AI

**AI-native project operations for teams that build software.**

ForgeFlow AI is the public Community Showcase derived from a private production platform for project management, GitHub intelligence, AI-assisted engineering, governed automation, progress tracking, and team review workflows.

The private upstream remains the active development and production repository. This public edition is intentionally curated so the architecture and product ideas are visible without publishing private team data, runtime state, credentials, submissions, or internal operational details.

## Highlights

- Role-aware student and professor workspaces
- Activity, timeline, calendar, project and review workflows
- GitHub contribution intelligence
- Persistent AI project copilot
- Repository retrieval with bounded lexical RAG
- Diff-aware code-quality review assistance
- AI debugging assistance
- Evidence-backed progress intelligence
- Project health scoring and daily/weekly intelligence
- Seven-specialist multi-agent orchestration
- Governed AI actions using `propose -> approve -> execute`
- CI, E2E, dependency auditing and security controls

## Public vs private boundary

The public showcase does **not** contain real team/user data, runtime SQLite databases or sessions, environment secrets or tokens, private submissions or grading records, production credentials, private GitHub automation configuration, or internal deployment state.
