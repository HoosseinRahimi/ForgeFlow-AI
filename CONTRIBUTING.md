# Contributing to ForgeFlow AI

Thanks for your interest in ForgeFlow AI.

This repository is the curated public Community Showcase. The private upstream remains the authoritative development repository, so not every internal component is available here.

## Good public contributions

Public contributions are especially welcome for:

- documentation improvements
- architecture diagrams and explanations
- product/UX proposals
- security-hardening suggestions
- reproducible bug reports against public material
- open-source tooling or examples that do not depend on private upstream data

## Security and privacy rules

Do not include credentials, private repository content, personal data, runtime databases, private submissions, internal deployment details, or copied secrets in issues or pull requests.

For security-sensitive findings, follow `SECURITY.md` instead of publishing exploit details.

## Pull requests

Keep changes focused, explain the motivation, and document any public behavior or architectural assumption you change. Public contributions must preserve the boundary between this showcase and the private production repository.
